Panduan Integrasi Google Apps Script (Auto-Sync Google Sheets)

Aplikasi ini dapat membaca data dokter langsung dari Google Sheets. Agar aplikasi juga bisa mengirim dan menyimpan data sesi handover serta pasien secara otomatis ke lembar kerja Google Sheets tanpa hambatan login berulang, ikuti 4 langkah mudah berikut:

1
Buka Apps Script di Google Sheets:
Buka spreadsheet Anda di browser, klik menu Ekstensi (Extensions) → Apps Script.
2
Salin Kode Backend Script:
Hapus kode default pada editor, lalu salin seluruh kode dari kotak di bawah ini dan tempelkan. Simpan file (Ctrl+S).
3
Terapkan Sebagai Web App:
Klik tombol biru Terapkan (Deploy) di kanan atas → Penerapan baru (New deployment) → Pilih tipe Aplikasi Web (Web app).
Atur: Jalankan sebagai: Saya | Yang memiliki akses: Siapa saja (Anyone).
4
Tempelkan URL Web App:
Salin URL yang diberikan (berakhiran /exec), lalu tempelkan ke kolom "Web App Apps Script URL" pada halaman Master Data aplikasi ini dan klik Simpan.
